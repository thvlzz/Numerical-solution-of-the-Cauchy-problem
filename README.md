# Numerical-solution-of-the-Cauchy-problem
Программа представляет собой приложение на Python с графическим интерфейсом (GUI) на основе `tkinter`. Она предназначена для численного решения обыкновенного дифференциального уравнения (ОДУ) методом Рунге-Кутты 4-го порядка с автоматическим подбором шага интегрирования.

## Математическая постановка
Программа решает следующую задачу Коши на отрезке $0.0 < x \le 2.5$:

$$
\begin{cases}
\frac{dy}{dx} = [x + y(x)]\{\cos[(x + y(x))^2]\}^2 \\
y(0) = 0
\end{cases}
$$

Численное интегрирование проводится с контролем локальной погрешности. Программа автоматически корректирует длину шага $h$ для достижения заданной точности $\varepsilon = 10^{-10}$.

## Ключевые особенности

* Метод Рунге-Кутты (RK4): Классический алгоритм 4-го порядка точности.
* Адаптивный шаг: Использование правила Рунге (сравнение результатов полного шага и двух половинных) для динамического изменения шага интегрирования.
* Удобный GUI:
  * Поле ввода для изменения начального условия $y(0)$ (по умолчанию задано `0.0` согласно условию задачи).
  * Кнопка `Start`/`Stop` для управления процессом вычислений.
  * Интерактивный график функции $y(x)$, который анимированно строится в реальном времени по мере выполнения расчетов.
